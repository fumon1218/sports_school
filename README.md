# 스포츠 마을 (체육 중점 특수학교 홍보용 웹 게임) — 시제품

링크 하나로 PC·태블릿·휴대폰에서 바로 실행되는 3D 웹 게임입니다. 설치와 계정이 필요 없습니다.
광장을 걸어 다니다 체육관에 들어가면 스포츠 체험 게임이 열립니다.

## 지금 되는 것
- **열린 마을**: 정문에서 시작해 학교 안을 걸어 다니고, 울타리 밖 자연 지대(숲, 들판, 호수)도 둘러볼 수 있습니다.
- **체험 구역**: 탁구·육상 구역의 동그란 빛에 서면 해당 게임이 바로 열립니다. 
- **체육관**: 입구 포털로 들어가면 5개 종목 로비가 열리고 메달 수집판이 있습니다.
- **조작**: 방향 버튼 하나(키보드는 방향키·WASD) + 행동 버튼 하나(스페이스·엔터). '안내' 버튼은 다음 갈 곳까지 길을 찾아 데려다 줍니다.
- **쉬운 모드**(기본 켬): 천천히 걷고, 동그란 빛에 서 있으면 자동 입장, 게임은 가장 쉬운 방식으로 시작합니다.
- **접근성**: 실패·감점·시간 제한 없음, 움직임 줄이기, 캐릭터 고르기(소년·휠체어 선수).
- 게임은 옥쌤의 즐거운 교실 씽씽별 체육(`games/oks/`)을 그대로 연결했습니다.

## 실행
정적 파일만 있습니다. 로컬에서는 폴더에서 `python3 -m http.server 8000` 후 http://localhost:8000 을 엽니다.
(파일을 더블클릭해서 여는 방식은 브라우저 보안 때문에 모듈이 안 불러와집니다.)

## GitHub Pages 배포
1. 새 빈 저장소를 만들고 이 폴더 내용을 그대로 올립니다.
2. Settings → Pages → Branch: main / (root) 저장.
3. `https://<계정>.github.io/<저장소>/` 로 접속합니다.

## 폴더
- `index.html`, `css/`, `js/` : 월드(Three.js r186, `vendor/three/`에 포함되어 인터넷 없이도 동작)
- `js/config.js` : 학교 이름, 건물·체험 구역 배치, 종목, 자연물 — 여기만 고치면 됩니다
- `js/placeholders.js` : 임시 도형 모델
- `assets/models/` : glb 를 넣는 곳 (자세한 방법은 그 폴더의 README)
- `games/oks/` : 옥쌤의 즐거운 교실에서 가져온 스포츠 게임과 필요한 파일만 담은 사본

## 공개 저장소 점검
- 학교 이름은 config.js 의 `schoolName` 에서 바꿉니다. 연락처, 주소, QR, 학생 사진은 넣지 않았습니다.
- `games/oks/` 안의 기관 이름 문구는 일반 표현으로 바꿔 두었습니다.
- 안내 인물(옥쌤 그림)은 `assets/ui/mascot.png`입니다. 학교 마스코트가 정해지면 같은 이름으로 바꿔 넣으면 됩니다.
