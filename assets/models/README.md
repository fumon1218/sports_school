# 3D 모델 넣는 곳

이 폴더에 아래 이름으로 glb 파일을 넣으면, 임시 도형이 자동으로 실제 모델로 바뀝니다. (코드 수정 불필요)
파일이 없는 건물은 임시 도형으로 계속 보입니다. 브라우저 콘솔에 404가 뜨는 것은 정상입니다.

| 파일 | 대신하는 것 | 이름 정하는 곳 |
|---|---|---|
| gym.glb | 체육관동 | js/config.js 의 BUILDINGS |
| teacher.glb | 교사동 | 〃 |
| pool.glb | 수영장동 | 〃 |
| dorm.glb | 생활관 | 〃 |
| gate.glb | 정문 게이트 | js/config.js 의 PROPS |
| track.glb | 운동장 | 〃 |

## 맞추는 방법
- 크기: config.js 의 w(가로)·d(세로)·h(높이)에 맞춰 자동으로 줄이거나 늘립니다. 바닥이 y=0, 가운데가 건물 자리에 오도록 자동 정렬합니다.
- 방향: 모델 앞면이 광장(남쪽)을 보지 않으면 rotY 를 90, 180, 270 으로 바꿉니다.
- 간판: 모델의 빈 간판 판 높이에 맞게 signY 를 조절합니다. 글자는 앱이 얹으므로 모델에는 글자를 넣지 마세요.
- 용량: 건물 하나에 1MB 안팎(저폴리)을 권장합니다. 모바일 성능과 로딩 속도에 유리합니다.
- 입장 포털(체육관 문 앞)은 문 위치에 맞춰 config.js 의 GYM_PORTAL 좌표를 조절합니다.
